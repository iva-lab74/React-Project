# IP Address Tracker

My IP tracker app, using React instead.

## Live Demo
https://react-project-seven-virid.vercel.app

## Features
- Search any IP/domain
- Shows IP, location, timezone, ISP
- Interactive Leaflet map

## Setup
1. `npm install`
2. `npm run dev`

## Reflection
So for this project I build an IP Tracker in React using VITE. The app lets the user search and IP address, and see it pop up on the map. The biggest challenge was the API key. I stored it in a env. file, but my page came up blank. I learned that VITE only reads variables with VITE. So when I figured that out everything proceeded smoothly.
